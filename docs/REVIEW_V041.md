# v0.4.1: fixes from an independent adversarial review, and the tests that prove them

Every test below is in `tests/test_v041.py`. The fix tests were written before the fixes. Run against the v0.4.0 code
(commit 40c8000, with the installed v0.4.1 package hidden so no new module leaks in), **36 of the file's 45 tests
fail**. The 9 that pass on v0.4.0 are guards for behaviour that must not change: a correct "moderated from … to", a correct
"decreased by", a wrong endpoint, "fell by 0.8 per cent" (already flagged), a pure opinion, coarser-precision rounding
(2), "Jal Jeevan Mission" as one name, and an evaluative opinion.
